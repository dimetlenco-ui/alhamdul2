## Research project: Mobile Money as Informal Insurance

A short development economics research proposal. Its question: when a rainfall shock hits, do rural Ugandan households that use mobile money smooth consumption better than those that don't?

The full proposal is in [`index.html`](index.html). It covers the question, hypotheses, data (UNPS / LSMS-ISA and CHIRPS rainfall), empirical strategy, limitations, timeline, and references. With GitHub Pages turned on for this repo, it serves as the site's home page.
